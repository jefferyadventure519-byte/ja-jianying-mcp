# 给 AI 的安装指令（ja-jianying）

你（Claude）正在帮一位同事把「用 Claude 生成剪映草稿」装到他的电脑上。请严格按下面的顺序做。容易出错的环节都写成了脚本，你负责运行脚本、读结果、用大白话和使用者沟通。

## 边界（先读）

- 只让使用者做「点击」类的事（装软件、打开剪映、点导出、重开程序），**不要让他敲命令**。命令都由你来跑。
- 不要动 Claude 配置里别的注册项，不要动剪映的安装和设置。
- 自检只会**新建**一个名字以「JA自检_」开头的草稿，不会碰使用者已有的草稿。
- 任何一步失败，先把脚本输出的原因用一两句话告诉使用者，再决定下一步；不要反复重试同一条命令。
- 只在 Windows 上验证过。使用者是 Mac 时，先说明「没有验证过」，由他决定要不要继续。

## 第 1 步：确认前提

1. **剪映专业版**已经装好，并且打开过一次（这样才有草稿目录）。实测过的版本是 11.1.0.14287 和 11.6.0.14552，其他版本第 3 步会提醒。
2. **Python**：运行 `python --version`（不行再试 `py -3 --version`），需要 3.10 或更新，推荐 3.11。没有的话，请使用者去 python.org 下载 3.11 的 Windows 安装包，安装时勾上「Add python.exe to PATH」，装完告诉你。
3. 问使用者要不要**听写**（把片子里的人声转成字幕）。要的话第 4 步加 `--with-asr`，会多下载约 460 MB（Windows 上占约 0.9 GB 磁盘）。

## 第 2 步：下载本仓库

目标位置：`%LOCALAPPDATA%\ja-jianying\kit`。

- 有 git：`git clone https://github.com/jefferyadventure519-byte/ja-jianying-mcp.git "%LOCALAPPDATA%\ja-jianying\kit"`
- 没有 git：下载 `https://github.com/jefferyadventure519-byte/ja-jianying-mcp/archive/refs/heads/main.zip`，解压后把里面那层目录改名放到上面的位置。

下载失败多半是访问不了 github.com，请如实告诉使用者，由他解决网络后再继续。

## 第 3 步：只检查，不改动

在仓库目录里运行：

```
python ja/scripts/install.py --check-only
```

读输出最后的「结果」一段：

- 有「不能继续的原因」：停下，把原因讲给使用者听。
- 只有「提醒」：讲清楚，问使用者要不要继续。最常见的是「剪映版本没有实测过」——可以继续，装完靠自检确认。

## 第 4 步：安装

```
python ja/scripts/install.py
```

要听写就加 `--with-asr`。它会建运行环境、装依赖、在 Claude 里注册（名字 `jianying`）、装上规则技能。逐条读「完成 / 失败 / 跳过」：

- 「在 Claude 里注册」失败并提示已有同名注册：说明这台电脑以前装过。把旧注册指向的位置告诉使用者，问他是否替换；同意后加 `--force` 重跑。
- 提示桌面版配置里也有同名注册：告诉使用者两处同时存在会重复加载，建议只留一处，由他决定，不要自己去删。
- pip 下载失败：脚本会自动换清华镜像再试一次；还不行就如实说网络问题。

## 第 5 步：自检

安装输出的最后一行有「自检命令」，原样运行。它会像你以后一样，通过 MCP 调用每个工具：新建「JA自检_…」草稿，放彩条、配音、字幕、标题，保存后核对草稿内容，再试一次「不覆盖已有草稿」和「不碰别的草稿」两道保护。

把结果讲给使用者：通过几项、不通过几项、记录几项。「记录」不是失败，最常见的是配音没联网，脚本已经改用备用字幕继续。

## 第 6 步：请使用者在剪映里看一眼

1. 打开剪映（开着的话回到首页；列表里没有就重开剪映），打开「JA自检_…」草稿。
2. 应该看到：竖版彩条、顶部黄色标题、底部白字黑边字幕、一段配音。点一条字幕，右侧有「字幕」页签。
3. 点右上角「导出」，确认能导出。
4. 看完可以在剪映里把自检草稿删掉。

## 第 7 步：收尾

告诉使用者：

1. **完全退出并重开 Claude**，新会话里才有剪映的工具。
2. 以后说「用剪映给这段视频加字幕和配音」之类的话就行，规则技能 `ja-jianying` 会自动带上。
3. 导出永远要他自己点；剪映打开过的草稿 AI 读不回来，要改就让 Claude 新建一版。
4. 剪映开着自动更新，升级后先让 Claude 跑一次自检。

最后用下面的格式汇报，数字照实填：

```
安装结果：成功 / 没装完（原因：…）
剪映版本：…（实测过 / 没实测过）    听写：装了 / 没装
自检：通过 … 项，不通过 … 项，记录 … 项
在剪映里看过自检草稿：是 / 否
需要你做的：…
没有验证的：…
```
